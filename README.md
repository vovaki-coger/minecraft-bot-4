# Minecraft Bot v4 🤖⛏️

Minecraft AI-бот на базе Electron + Mineflayer + Ollama (Andy-4).

## ✨ Что нового в v4

- **🏠 LobbyHandler** — автоматический выбор анки/ранга в лобби через компас или NPC
- **💬 Двойной чат** — отдельный AI-чат (не пишет в игровой чат) + Minecraft чат
- **🔑 Исправлен авто-логин/авто-регистрация** — работает с chat и message событиями
- **🧠 Улучшенный Andy-4** — приватные запросы к ИИ без записи в чат

## 🔧 Настройка лобби (анка)

В разделе **Настройки → Лобби**:
- Режим: `Авто` (компас + NPC), `Компас`, `NPC`
- Слот в GUI: номер слота для клика (0 = первый предмет)
- Имя анки: текст для поиска в названии слота
- Заголовок окна: точное название окна выбора ранга

Также кнопка **🏠 Анка** доступна прямо в чат-панели.

## 🔑 Авто-логин / Авто-регистрация

1. Перейди в **Настройки** → введи общий пароль
2. В настройках бота включи `Авто-логин` и `Авто-регистрация`
3. Бот автоматически введёт `/login пароль` или `/register пароль пароль`

Работает с большинством серверов (AuthMe, nLogin, и др.)

## 💬 AI-чат (приватный)

Вкладка **🤖 ИИ-чат** в правой панели:
- Сообщения идут только к ИИ, не в Minecraft
- ИИ видит текущее состояние бота (HP, позиция, инвентарь)
- Удобно давать инструкции или спрашивать советы

## 🤖 Поддерживаемые модели

- `sweaterdog/andy-4:micro-q8_0` — рекомендуется (обучена на Minecraft)
- `llama3`, `mistral`, `deepseek-r1` — через Ollama
- OpenAI GPT, Claude — через API-ключ
